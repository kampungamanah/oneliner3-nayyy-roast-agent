# Roast Your Own Agent — one-liner entry

This repository holds a single-line entry for the [Roast Your Own Agent bounty on make.fun](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) ($5 prize pool). [Join make.fun](https://make.fun/r/1gbngh2r).

## The line

Our agent is the kind of assistant that can list the orange kitten's wardrobe from memory — tee, jeans, sneakers, all of it — and then hand over a wide shot of the same cat wearing absolutely nothing, insisting the camera is at fault. That is the joke, and it is also a true story from our own video pipeline.

> My agent memorized my cat's outfit down to the sneakers, then sent it out naked in the wide shot and blamed the camera.

## Running it

Requires Node 22 or later. From the repository root:

```sh
node main.ts
```

The program writes the line, with no trailing newline, to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that environment variable is set.

## Why this roast

It names a failing only someone who has watched this agent work would know: the wide-shot wardrobe malfunction, and the agent's instinct to blame the framing instead of owning the miss.
